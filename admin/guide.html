1Les citoyens

Le site public est starflexone.com, en français et en kreyòl (boutons FR / KR en haut).

Créer un compte

  1. Aller sur starflexone.com/register.html.
  2. Remplir : nom, email et/ou téléphone, commune, année de naissance, mot de passe (6 caractères minimum).
  3. Un code à 6 chiffres confirme le compte. Pour l'instant aucun envoi SMS/email n'est branché : le code s'affiche à l'écran, uniquement pour la personne qui vient de s'inscrire.
  4. Le citoyen arrive dans « Mon espace ».

Se connecter ensuite

starflexone.com/login.html avec l'email ou le numéro de téléphone, et le mot de passe.

Dans « Mon espace »

Formations, consultations et sondages, volontariat, notifications, profil.

Certificat National de Participation Citoyenne

Délivré automatiquement : Bronze à 30 points, Argent à 75, Or à 150. Chaque certificat porte un code (ex. SF-00001-XXXXX) que tout le monde peut vérifier sur starflexone.com/certificate.html.

Il n'y a pas encore de « mot de passe oublié » pour les citoyens. En cas d'oubli, contactez-nous (section 6).

Publier une actualité ou un événement

  1. Onglet Actualités & événements.
  2. Choisir « Actualité » ou « Événement », puis la date, le titre, le lieu, un résumé, le texte complet et éventuellement une photo.
  3. Publier (visible sur le site), ou Enregistrer en brouillon (invisible, à finir plus tard).

Les publications apparaissent sur la page Ressources : les actualités dans « Actualités », les événements dans « Événements » (les prochains en premier). Tant que rien n'est publié, la page garde ses textes de présentation.

Modifier un texte du site

  1. Onglet Textes du site.
  2. Dans « Chercher un texte du site », tapez quelques mots de la phrase à changer.
  3. Cliquez Modifier : la phrase actuelle s'ouvre. Écrivez la nouvelle version, puis Enregistrer.
  4. Pour la version en kreyòl de la même phrase, cliquez Version kreyòl.
Le site affiche le changement dans les 2 minutes. Une phrase modifiée seulement en français garde son ancienne version en kreyòl : pensez à faire les deux.

Photos

Onglet Photos : JPG, PNG, WEBP ou GIF, 3 Mo maximum par image. Les photos servent ensuite dans les actualités et événements.

4Vos Ajan : chauffeurs et produits HaitiBiznis

Oui, vos Ajan peuvent inscrire des chauffeurs et vendre les produits de l'écosystème HaitiBiznis. Cela ne se fait pas sur starflexone.com, mais avec le code Ajan de chacun dans les outils HaitiBiznis. Tout ce qu'ils apportent est compté pour eux et pour STARFLEX.

Étape 1 : chaque Ajan a son code

  • L'Ajan s'inscrit (gratuit) comme Ajan HaitiBiznis/LajanMaker et reçoit son code et son QR une fois approuvé par HaitiBiznis.
  • Envoyez-nous ensuite la liste des codes de vos Ajan. Nous vérifions d'abord chaque code, puis nous les relions à STARFLEX avec votre accord.

Étape 2 : inscrire un chauffeur (MsouWout)

  • Le chauffeur scanne le QR de l'Ajan, ou ouvre le lien de l'Ajan : la page d'inscription chauffeur MsouWout s'ouvre avec le code déjà rempli.
  • Sinon, il s'inscrit sur msouwout.com et écrit le code dans « Kòd Ajan ».
  • Le chauffeur apparaît dans votre tableau de bord : inscrit, puis approuvé, puis actif.

Étape 3 : les autres produits

Le même code Ajan est reconnu sur MyPlopPlop (commerces et clients) et sur Tikè Lakay (billets). Chaque inscription ou vente faite avec le code est attribuée à l'Ajan et à STARFLEX.
